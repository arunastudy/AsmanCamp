## 📋 Что нужно сделать

### 1. Узнайте свой Telegram ID

Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram

### 2. Обновите SESSION_SECRET (важно!)

В файле `.env.local` замените `SESSION_SECRET` на надежный ключ:

```bash
# Сгенерируйте новый секрет (PowerShell):
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Вставьте результат в `.env.local`:
```env
SESSION_SECRET=ваш_сгенерированный_секрет
```

### 3. Инициализируйте тестовые данные

```bash
npm run init:test
```

Это создаст:
- Админа: `admin@asman-camp.com` / `admin123`
- Настройки в памяти

**ВАЖНО!** После выполнения команды, в выводе будет указано, что нужно обновить `ADMIN_TELEGRAM_USER_ID` на ваш реальный Telegram ID.

### 4. Обновите настройки

В файле `lib/db/index.ts` найдите и измените:

```typescript
const adminTelegramId = await createSetting(
  'ADMIN_TELEGRAM_USER_ID',
  'YOUR_TELEGRAM_USER_ID' // ← Замените на ваш ID
);
```

Или после запуска `npm run init:test` выполните в коде:

```typescript
// В реальном проекте это будет SQL запрос к БД
UPDATE settings SET value = 'ВАШ_TELEGRAM_ID' WHERE key = 'ADMIN_TELEGRAM_USER_ID';
```

### 5. Запустите приложение

```bash
npm run dev
```

### 6. Войдите в админку

1. Откройте http://localhost:3000/auth/admin/login
2. Введите `admin@asman-camp.com` / `admin123`
3. Получите код в Telegram
4. Введите код
5. Вы в админ-панели! 🎉

## 🔐 Как это работает

```
1. Админ вводит email/пароль
   ↓
2. Система проверяет в БД
   ↓
3. Генерируется 6-значный код
   ↓
4. Код отправляется в Telegram
   ↓
5. Админ вводит код
   ↓
6. Доступ к админ-панели!
```

## 🛡️ Защита

- `/admin/*` - только для админов
- `/dashboard/*` - только для пользователей (когда реализуете)
- Админы не могут попасть на страницы пользователей
- Пользователи не могут попасть в админку
- Лендинг (`/`) доступен только неавторизованным

## 🗄️ Подключение реальной БД

Сейчас используется временное хранилище в памяти. Чтобы подключить PostgreSQL:

1. Установите драйвер:
```bash
npm install pg
```

2. Добавьте в `.env.local`:
```env
DATABASE_URL=postgresql://user:password@localhost:5432/asman_camp
```

3. Создайте таблицы (см. `ADMIN_SETUP.md`)

4. Обновите функции в `lib/db/index.ts`

Подробнее см. `ADMIN_SETUP.md`

## 🐛 Проблемы?

### Код не приходит в Telegram
- Проверьте, что бот запущен
- Убедитесь, что Telegram ID указан правильно
- Проверьте токен бота в `.env.local`

### Ошибка сессии
- Установите `SESSION_SECRET` в `.env.local`
- Очистите cookies браузера
- Перезапустите сервер

### Middleware не работает
- Удалите папку `.next`
- Перезапустите `npm run dev`
