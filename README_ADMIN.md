## 🗺️ Роуты

### Публичные
- `/` - Лендинг (только для неавторизованных)
- `/auth/admin/login` - Вход админа
- `/auth/admin/verify` - Верификация кода

### Защищенные
- `/admin` - Админ-панель (только админы)
- `/dashboard` - Личный кабинет (только пользователи, когда реализуете)

### API
- `POST /api/auth/admin/login` - Вход
- `POST /api/auth/admin/verify` - Проверка кода
- `POST /api/auth/admin/logout` - Выход
- `GET /api/auth/me` - Текущий пользователь

## 🔒 Безопасность

- ✅ Пароли хешируются с bcrypt (12 раундов)
- ✅ Сессии защищены железной криптографией (iron-session)
- ✅ CSRF защита встроена в Next.js
- ✅ HTTP-only cookies
- ✅ Коды верификации истекают через 10 минут
- ✅ Разделение ролей на уровне middleware

## 📱 Процесс входа

```
Админ вводит email/пароль
         ↓
Проверка в БД
         ↓
Генерация 6-значного кода
         ↓
Отправка в Telegram
         ↓
Админ вводит код
         ↓
Проверка кода
         ↓
✅ Вход выполнен!
```

## 🎯 Таблицы БД (когда подключите)

### users
```sql
id            SERIAL PRIMARY KEY
email         VARCHAR(255) UNIQUE NOT NULL
password      VARCHAR(255) NOT NULL
role          VARCHAR(50) NOT NULL DEFAULT 'user'
telegram_id   VARCHAR(100)
created_at    TIMESTAMP DEFAULT NOW()
```

### settings
```sql
id            SERIAL PRIMARY KEY
key           VARCHAR(255) UNIQUE NOT NULL
value         TEXT NOT NULL
created_at    TIMESTAMP DEFAULT NOW()
```
